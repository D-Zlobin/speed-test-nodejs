# Speed-тест на Node.js

Консольный скрипт без внешних зависимостей, который измеряет скорость скачивания с помощью 10 последовательных HTTP/1.1-запросов.

## Требования

- Node.js 18 или новее.
- URL-адрес с протоколом `http://` или `https://`, по которому доступен ресурс для скачивания.

## Использование

```sh
node speed-test.js <url>
```

Пример:

```sh
node speed-test.js https://samplelib.com/jpeg/sample-photo-3840x2160.jpg
```

Пример вывода:

```text
Successful requests: 10/10
Failed requests: 0
Average request time: 125.43 ms
Total downloaded: 10485760 bytes (10.49 MB)
Download speed: 669.35 Mbps
```

Скрипт дожидается полного получения каждого ответа перед началом следующего запроса. Ответ считается успешным только при статусе `200–299` и полном, корректном формате HTTP-сообщения. Автоматические переходы по перенаправлениям не выполняются.

В интерактивном терминале во время выполнения показывается полоса прогресса с номером текущего запроса и количеством завершённых попыток. Индикатор выводится в `stderr` и обновляется на одной строке, поэтому итоговые результаты в `stdout` остаются отдельными. При перенаправлении вывода или запуске без интерактивного терминала индикатор отключается.

## Расчёты и единицы измерения

В расчётах учитываются только успешные ответы:

- **Среднее время запроса** = сумма длительностей успешных запросов / количество успешных запросов.
- **Общий объём скачанных данных** = сумма всех байтов успешных HTTP-ответов.
- **Скорость скачивания** = общее количество байтов × 8 / сумма длительностей успешных запросов.

Используются десятичные приставки:

- `1 MB (МБ) = 1 000 000 байт`;
- `1 Mbps (Мбит/с) = 1 000 000 бит в секунду`.

Измерение времени запроса начинается перед открытием соединения и включает установление соединения, TLS-рукопожатие для HTTPS, отправку запроса и получение полного ответа. Запуск скрипта и вывод результатов не учитываются.

В количество байтов входят статусная строка, HTTP-заголовки и тело каждого ответа в том виде, в котором они были переданы, включая служебные данные chunked-кодирования и сжатие. Тела ответов не распаковываются. Байты запросов и служебные данные протоколов TCP/IP/TLS не учитываются.

## Ошибки и коды завершения

- При отсутствии или некорректности URL, неподдерживаемом протоколе либо отсутствии успешных ответов процесс завершается с кодом `1`.
- Информация о неудачной попытке выводится, после чего скрипт продолжает работу, пока не будет выполнено ровно 10 попыток.
- Если успешен хотя бы один ответ, выводятся частичные результаты, а процесс завершается с кодом `1`, указывающим на неполное измерение.
- Если все запросы успешны, процесс завершается с кодом `0`.

Поддерживается только HTTP/1.1 поверх HTTP или HTTPS. HTTPS-сертификаты проверяются с использованием настроек Node.js по умолчанию.
